# 🚗 Logos - Retífica de Motores

Landing page moderna e responsiva para uma retífica de motores localizada em Juazeiro do Norte - CE. O projeto apresenta os serviços oferecidos pela empresa, informações de contato e localização.

## 📋 Sobre o Projeto

A **Logos** é uma empresa especializada em retífica de motores nacionais e importados, com mais de 10 anos de experiência no mercado. Esta landing page foi desenvolvida para apresentar os serviços da empresa de forma clara e profissional, facilitando o contato com potenciais clientes.

## ✨ Funcionalidades

- 🎨 Design moderno e responsivo
- 📱 Totalmente adaptável para dispositivos móveis
- 🚀 Navegação suave entre seções
- 💬 Integração direta com WhatsApp
- 🗺️ Mapa interativo com localização da empresa
- ♿ Acessibilidade e SEO otimizados

## 🚀 Como Usar

### Opção 1: Abrir diretamente no navegador

1. Clone o repositório:
```bash
git clone https://github.com/sougabrielxd/logos.git
cd logos
```

2. Abra o arquivo `index.html` diretamente no seu navegador.

### Opção 2: Usar um servidor local

Para uma melhor experiência de desenvolvimento, use um servidor local:

```bash
# Com Python 3
python -m http.server 8000

# Com Node.js (usando http-server)
npx http-server

# Com PHP
php -S localhost:8000
```

Depois acesse `http://localhost:8000` no navegador.
